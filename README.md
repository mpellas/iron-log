# 90Strong (iron-log)

Personal Planet Fitness workout tracker (PWA).

## Features
- LOG / HISTORY / GAINS / AI REC / PLAY / HELP
- **Video Combos** group for demo-linked exercises with looping YouTube player
- Seeded demos: Multi-Level Bicep Curl Combo, Ab Dumbbell Combo, Squat Cardio Combo, Full Body Flamer, Shoulder Barbell Combo, Full Body Dumbbell
- Export/import, AI plans (Claude), photo scan, unilateral tracking, etc.

Open `index.html` as a static site or GitHub Pages.
